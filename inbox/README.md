# 资料收件箱

这里是新下载或新生成资料的临时入口，不是学习目录。

每个文件进入时补一行元数据：

```text
来源：ChatGPT 导出 / 面经 / 官方网页 / 论文 / Agent 仓库
日期：YYYY-MM-DD
主题：Transformer / 训练 / RAG / Agent / 其他
状态：待去重 / 待核验 / 已提炼 / 暂存
隐私：无 / 需要脱敏
```

处理完成后只允许三种去向：

1. 面经线索 → 根目录面经索引或 `sources/`；
2. 已核验教学内容 → `learning/` 与对应 `labs/`；
3. 暂时不纳入主线 → 保留在这里，标明原因。

不要把新的长 Markdown、Notebook 或网页复制件直接堆到仓库根目录。
