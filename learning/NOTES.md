# 教学偏好与工作笔记

- 教学顺序：基础 → Transformer → 训练 → 后训练 → 推理 → RAG → Agent。
- 每个单元都要有 What / Why / Mechanism / Code / Trade-off / Interview / Validation。
- 先给学习地图和可复核材料，再开始互动学习；不要提前扩展后续阶段。
- Mac 上的 GPU 内容采用 `RUNNABLE_CPU`、`MPS_OPTIONAL`、`SOURCE_READ`、`REMOTE_GPU` 四级标记。
- 没有用户展示理解或纠正误解前，不写 learning record；本目录的记录文件保持空白是正常状态。
