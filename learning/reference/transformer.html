Decoder-only 数据流

input_ids [B,T]
  → embedding [B,T,D]
  → N × decoder block [B,T,D]
  → final norm [B,T,D]
  → lm_head [B,T,V]
  → next-token logits

Attention

Q = XWQ, K = XWK, V = XWV
scores = QKᵀ / √Dh + mask
A = softmax(scores)
O = AV

internal: [B,T,D] → [B,H,T,Dh]

结构差异

结构Q headsK/V heads主要影响
MHAHH表达充分，KV cache 大
MQAH1KV cache 小，可能牺牲表达
GQAHHkv折中；Hkv 必须整除 H

Block

h = x + Attention(Norm(x))
y = h + SwiGLU(Norm(h))

RMSNorm(x) = x / √(mean(x²)+ε) · weight

KV Cache 关键句

Prefill 一次处理 prompt；decode 每步只计算新 token 的 Q/K/V，并复用每层历史 K/V。KV cache 主要减少重复计算，不是把所有 attention 复杂度神奇地变成线性。
