算法不变量

模式核心不变量复杂度
heap top-k堆中保留当前最大的 k 个元素O(n log k)
BFS队列按距离层扩展，首次到达即最短O(V+E)
LRU哈希表定位节点，链表头为最近使用get/put O(1)
滑动窗口窗口始终满足当前约束，右扩左缩通常 O(n)

数值公式

softmax(z)i = exp(zi - max(z)) / Σj exp(zj - max(z))
CE = -log p(y|x)
KL(P||Q) = Σx P(x) [log P(x) - log Q(x)]
m_t = β1 m_(t-1) + (1-β1) g_t
v_t = β2 v_(t-1) + (1-β2) g_t²
m̂_t = m_t / (1-β1^t),  v̂_t = v_t / (1-β2^t)

PyTorch 诊断顺序

  1. shape、dtype、device 是否一致；
  2. loss 是否可计算且 labels 是否错位；
  3. 梯度是否为 None/NaN；
  4. optimizer 是否真正更新；
  5. train/eval、dropout、padding 和 checkpoint 是否正确。
