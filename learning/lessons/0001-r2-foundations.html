Lesson 0001 · R2

把“基础”变成可验证的代码

本课的胜利条件不是记住一堆名词，而是能从输入、shape、公式、更新和失败路径解释一个最小训练问题。

今天只做一个闭环：算法不变量 → stable math → PyTorch tensor/device → 测试。

1. 三个必须稳定的 mental model

算法

先说不变量，再说数据结构，最后给复杂度。比如 top-k 的 heap 只保留当前最大的 k 个元素，因此每个新值最多触发一次 log k 调整。

数值

softmax 的核心不是公式本身，而是先减去最大 logit，避免指数溢出；cross entropy 可以直接在 logits 上用 log-sum-exp 计算。

训练

训练 bug 的顺序通常是 shape/dtype/device → labels/loss → gradient → optimizer → train/eval → 数据和学习率。不要一上来改模型结构。
