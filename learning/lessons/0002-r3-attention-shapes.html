先追 shape，再理解 Attention

Transformer 面试最常见的失分不是不会公式，而是说不清每一次 reshape、transpose、mask 和复杂度。

1. 从 X 到 O

X [B,T,D]
Q=XWQ, K=XWK, V=XWV
split → [B,H,T,Dh],  D = H·Dh
scores = Q @ Kᵀ / √Dh  → [B,H,T,T]
mask + softmax → [B,H,T,T]
context = A @ V          → [B,H,T,Dh]
merge → [B,T,D]
Wo → [B,T,D]

2. 三个“为什么”

为什么除 √Dh？

点积方差随维度增长，softmax 更容易饱和；缩放让梯度区间更可用。

为什么 mask 在 softmax 前？

被屏蔽位置必须在归一化分母中消失；把概率算完再乘 mask 会留下错误归一化。

为什么 MQA/GQA 影响推理？

Query head 可以很多，但 K/V head 更少，历史 K/V 的存储量按 Hkv 缩小。
