把 Attention 组装成 Decoder Block

本课把 MHA、RoPE、GQA、RMSNorm、Residual 和 SwiGLU 串起来；GPU kernel 仍然不在本机通过条件里。

1. Pre-Norm block

h = x + Attention(RMSNorm(x))
y = h + SwiGLU(RMSNorm(h))

Residual 保留信息和梯度通路；Norm 控制激活尺度；FFN 在每个 token 上提供非线性容量。

2. RoPE 的最小理解

RoPE 不把位置向量直接加到 embedding，而是按 position 旋转 Q/K 的偶奇维度。position 0 的 sin=0、cos=1，因此是 identity；V 不做旋转。
