训练闭环与 Decoder LM 速查

一张用于面试回忆和 Lab 走读的压缩卡。完整解释请回到 Lesson 0004、Lesson 0005、Lesson 0006。

1. Shape 主线

input_ids      [B, T]
embedding      [B, T, D]
decoder blocks [B, T, D]
lm_head        [B, T, V]
shift logits   [B, T-1, V]
shift labels   [B, T-1]

2. Causal objective

位置 t 预测下一个 token xt+1，所以：

shifted_logits = logits[:, :-1, :]
shifted_labels = labels[:, 1:]
loss = sum(valid token NLL) / number of valid targets

IGNORE_INDEX = -100 用于 prompt/padding 等不应参与监督的位置。全是 ignore 时应显式报错，不能把 NaN 当成训练结果。

3. Update 与 accumulation

zero_grad → forward → loss_sum.backward()
         → accumulate loss_sum and valid_tokens
         → divide gradients by total valid_tokens
         → clip → optimizer.step()
字段诊断问题
loss标签对齐、mask、数据、学习率是否合理？
valid_tokens这个 batch 是否被 padding 或 prompt mask 稀释？
grad_norm梯度是否为空、爆炸或被频繁裁剪？
eval_loss是否过拟合、泄漏或 train/eval 状态错误？

4. Checkpoint 清单

  • 模型 state_dict；
  • optimizer state（如 Adam 的 moments）；
  • global step / epoch；
  • 模型配置与数据/实验版本；
  • 随机状态和恢复位置。
